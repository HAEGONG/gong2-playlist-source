## Prompt

Use case: logo-brand. Asset type: production logo icon for the open-source project gong2 Playlist Source, an OBS media playlist plugin. Primary request: Create one exceptionally simple, polished geometric logo combining a media playlist and a right-pointing play triangle into a single compact symbol. Flat vector-like solid shapes, clean precise edges, balanced negative space, readable at 32 px. Three horizontal rounded playlist bars forming the left portion; a clear right-facing play triangle as the focal point to the right, integrated as one coherent mark. Restrained contemporary teal/cyan accent with dark navy structural shapes, sufficient contrast on both white and dark gray README backgrounds. Square composition, centered symbol occupying roughly 75% of canvas with comfortable transparent padding. Actual transparent background. No text, no letters, no wordmark, no gradients, no shadows, no 3D, no mockup, no border, no decorative elements, no OBS trademark symbol. Deliver a single finished logo icon, not a sheet of alternatives.
